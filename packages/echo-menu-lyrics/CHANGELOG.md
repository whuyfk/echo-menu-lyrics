# 更新记录

## 0.2.0 — 2026-11-07

首个开源开发预览版。

- 原生 macOS 菜单栏歌词，支持应用菜单后及状态图标前停靠。
- 悬停显示播放模式、上一首、播放／暂停、下一首、收藏。
- 原文、译文优先、双语双行；支持逐字／逐句进度填色。
- 颜色跟随系统、歌曲封面或自定义；切歌时短暂保留已知封面色。
- 统一设置界面，支持字体、宽度、滚动、过滤、独立偏移及每屏配置。
- 区分实体显示器和桌面空间，默认固定在启动组件时所在桌面。
- 双语两侧使用完整菜单行高度，按可用空间适配字号。
- 提供 arm64 / x86_64 通用组件、源码及构建脚本。

本版为开发预览，兼容性与签名状态见
[兼容性说明](https://github.com/whuyfk/echo-menu-lyrics/blob/main/docs/COMPATIBILITY.md)。
