# 更新记录

## 0.3.3 — 2026-11-07

- 新增“原生紧凑双行”预览，两行直接绘制在原生状态栏项内。
- 原生紧凑双行随系统菜单栏跨桌面、全屏隐藏和顶部唤出。
- 保留现有大字号双行浮层，便于直接比较可读性与稳定性。

## 0.3.2 — 2026-11-07

- 所有单行歌词模式统一使用 macOS 原生状态栏项，跨桌面和全屏显隐交给系统管理。
- 单行模式下隐藏显示器和桌面范围设置，避免无效配置。
- 双行歌词保留现有实现，范围设置仅在双行模式显示。

## 0.3.1 — 2026-11-07

- 移除“鼠标所在显示器”选项，减少多屏使用时的跳动和设置复杂度。
- 旧配置中的鼠标跟随模式迁移为“主显示器”。

## 0.3.0 — 2026-11-07

- 移除左侧停靠，歌词固定使用右侧状态栏区域；旧配置自动迁移为右侧。
- 彻底移除辅助功能依赖和其他应用菜单几何读取。
- 双语双行改为覆盖插件自己预留的右侧状态栏空间。
- 新增双语单行模式，直接在原生状态栏内显示 `原文 · 译文`。

## 0.2.6 — 2026-11-07

- 歌词时间轴更新后先进入过滤等待状态，不展示尚未过滤的当前行。
- 制作人员过滤和自定义正则完成后才恢复歌词显示；失败回退也会先清除等待状态。
- 过滤等待期间显示歌名与歌手，并继续遵守隐藏、暂停和封面色等待策略。

## 0.2.5 — 2026-11-07

- 菜单栏 AX 与窗口几何读取迁移到串行后台队列，主线程只接收稳定后的最新样本。
- 常规几何兜底轮询由 0.12 秒降至 0.75 秒，状态项目录扫描由 2 秒降至 4 秒。
- AX 通知、前台应用、桌面切换、唤醒和屏幕变化仍会立即触发刷新。
- 使用 generation 丢弃过期后台结果，避免旧几何覆盖新布局。

## 0.2.4 — 2026-11-07

- 悬停控制按钮只在歌词实际展开且有歌曲时显示和进入无障碍树。
- VoiceOver 未悬停时提供“显示播放控制”入口，展开后暴露五个状态正确的按钮。
- 紧凑模式、无歌曲及歌词收缩状态不再暴露不可见或不可用的控制按钮。

## 0.2.3 — 2026-11-07

- 新安装默认使用“所有桌面与全屏空间”，右侧、主显示器、单行歌词不再请求辅助功能权限。
- 已有用户保存的桌面范围和布局保持不变。
- 仅当选择仅当前桌面、左侧、非主显示器或双语浮层时，才提示并读取菜单边界。
- 首次使用说明和权限设置页文案已统一。

## 0.2.2 — 2026-11-07

- 修复 macOS 状态栏窗口复用居中鼠标事件后，所有悬停按钮都被识别为“播放／暂停”的问题。
- 点击位置改为从当前屏幕鼠标坐标换算，确保五个视觉区域分别命中对应命令。

## 0.2.1 — 2026-11-07

- 修复菜单栏悬停播放控件在部分点击时序下没有触发的问题；物理点击统一由歌词视图按五个按钮区域命中。
- 保留五个控件的辅助功能语义，并补充点击区域与按钮顺序自检。

## 0.2.0 — 2026-11-07

首个开源开发预览版。

- 原生 macOS 菜单栏歌词，支持应用菜单后及状态图标前停靠。
- 悬停显示播放模式、上一首、播放／暂停、下一首、收藏。
- 原文、译文优先、双语双行；支持逐字／逐句进度填色。
- 颜色跟随系统、歌曲封面或自定义；切歌时短暂保留已知封面色。
- 统一设置界面，支持字体、宽度、滚动、过滤、独立偏移及每屏配置。
- 区分实体显示器和桌面空间，默认固定在启动组件时所在桌面。
- 双语两侧使用完整菜单行高度，按可用空间适配字号。
- 提供 arm64 / x86_64 通用组件、源码及构建脚本。

本版为开发预览，兼容性与签名状态见
[兼容性说明](https://github.com/whuyfk/echo-menu-lyrics/blob/main/docs/COMPATIBILITY.md)。
