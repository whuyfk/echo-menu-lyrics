# 兼容性与验证范围

## 运行条件

- macOS 13 或更新版本；EchoMusic 2.3.2 或更新版本。
- 原生组件包含 Apple Silicon（arm64）和 Intel（x86_64）切片。
- 歌词固定停靠在右侧，不读取其他应用的菜单结构。
- 所有歌词模式使用原生 `NSStatusItem`，跨桌面及全屏显隐由 macOS 管理。
- 双行歌词在固定状态栏高度内绘制，并在空间不足时自动缩小字号。
- 插件不请求辅助功能或屏幕录制权限。
- Windows / Linux 不启动本插件的原生组件。

## 已验证

- Apple Silicon、macOS 27.0.1、EchoMusic 2.3.2，单台无刘海外接显示器。
- JavaScript 检查覆盖配置、歌词时钟、翻译、过滤、取色、命令和订阅清理。
- Swift 自检覆盖状态栏空间、按钮命中、字形居中、双语字号和排版行为。
- 原生双行在 22 点和 30 点菜单栏高度下完成渲染检查。
- 实际播放命令、收藏与模式回传、歌词与译文、设置保存和封面取色。
- 单行和双行均随 macOS 菜单栏在全屏时隐藏，并在顶部唤出菜单栏时恢复。

## 尚待覆盖

Intel 真机、较早 macOS、刘海屏、多屏与热插拔、不同缩放组合、普通桌面之间
的完整切换、自动隐藏菜单栏、长时间运行及跨设备安装仍需进一步验证。
能编译对应架构不代表已完成该硬件的实际测试。
CI 会重建通用二进制，并验证提交二进制内嵌的源码摘要与当前源码一致；插件入口、
清单和文档则要求与重建产物逐字一致。Swift 编译器版本不同可能产生不同机器码。

## 签名与分发

预编译组件使用 ad-hoc 签名，没有 Apple Developer ID 签名及公证。
从 GitHub 下载到其他 Mac 时，系统可能阻止运行；本项目不保证所有设备均可
直接启动，也不提供关闭 Gatekeeper 或绕过系统保护的步骤。可按源码自行构建，
并在实际目标设备上验证。

EchoMusic 会对插件原生程序的首次启动及文件变化发起确认。
